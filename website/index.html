What it does

Sequencer Item Recovery is a short-term recovery tool, not a full undo history and not an automatic backup. It shows only deleted instructions or blocks; it intentionally ignores additions, settings changes, conditions and triggers.

Read the quick help or follow the detailed guide.

Install without N.I.N.A.'s plugin search

  1. Close N.I.N.A.

    Do not replace a plugin DLL while N.I.N.A. is running.

  2. Download and extract.

    Extract SequencerItemRecovery.zip into %LOCALAPPDATA%\NINA\Plugins\3.0.0\SequencerItemRecovery\. The file SequencerItemRecovery.dll must be directly inside that folder.

  3. Start N.I.N.A.

    Open Options → Plugins → Installed and check that Sequencer Item Recovery shows version 0.1.3.0.

  4. Open the tool.

    In Imaging, use Sequencer Item Recovery's four-square icon in the upper-right Tools group. The icon stays available after the panel is closed.

Manual downloads bypass the checksum verification performed by N.I.N.A.'s plugin manager. Download only from this product page or the publisher's official release location, and compare the SHA-256 value before installing.

During an active sequence

If an instruction disappears during a run, use N.I.N.A.'s lower-right 'Pause' control. Do not cancel the sequence. Then use Sequencer Item Recovery's 'Restore', confirm that N.I.N.A. is paused, check the restored item, and use N.I.N.A.'s resume control to continue. Details are in the detailed guide.
