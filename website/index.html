Sequencer Item Recovery is discontinued

This plugin is obsolete from N.I.N.A. 3.3 onward because N.I.N.A. provides native Undo, Redo and Edit History. It is no longer being developed or submitted to the official community plugin catalog. The old packages remain only as historical archives and are not recommended for installation.
