Detailed guide

A careful recovery guide for the Advanced Sequencer.

This guide explains what Sequencer Item Recovery watches, what each message means, and how to safely put a deleted instruction or block back into a sequence.

1. The problem Sequencer Item Recovery solves

An Advanced Sequencer is a tree: it can contain individual instructions such as an exposure, a dither or a wait; it can also contain larger blocks that hold several instructions. Deleting one row can therefore remove more than expected. Sequencer Item Recovery keeps the version that was loaded when the sequence was opened as a comparison baseline. It then watches the currently edited tree about once per second.

When a complete instruction or block disappears, Sequencer Item Recovery records it in its own list. It does not change the sequence by itself. That is why it can be used as a recovery aid without silently undoing intentional work.

2. Open the Sequencer Item Recovery panel

  1. Open the correct sequence.

    In N.I.N.A., open Sequencer, choose the Advanced Sequencer and load or create the sequence you are editing.

  2. Move to Imaging.

    Select Imaging in N.I.N.A.'s main navigation. Sequencer Item Recovery is an Imaging tool rather than a page in the main navigation.

  3. Show Sequencer Item Recovery.

    At the upper-right edge of the Imaging workspace, find the Tools group and click Sequencer Item Recovery's four-square icon. You can dock, float or resize the panel like other N.I.N.A. tools.

  4. Find it again later.

    If you close the panel, the icon remains in the Tools group. Click it again to reopen Sequencer Item Recovery. The docking position is stored in the active N.I.N.A. profile.

3. Read the panel

ColumnMeaning
Removed atThe local date and time when Sequencer Item Recovery first saw the item missing, shown as yyyy-MM-dd HH:mm:ss.
InstructionThe visible Sequencer name plus useful settings, such as exposure time or filter. It deliberately does not show JSON or internal type names.
ActionThe 'Restore' button for that one deleted item.

Click a column heading when you want a different order. By default, the newest deletion is first. A row disappears after a successful restore because the item is no longer missing.

New, unsaved sequences

Sequencer Item Recovery watches additions and deletions in the open Advanced Sequencer immediately, even while its Imaging panel is closed. You do not need to click 'Compare now' or wait two seconds before deleting a newly added instruction. A background check also follows changes to item settings about once per second.

4. Restore an item when the sequence is not running

  1. Identify the row.

    Use the name, settings and time to make sure that the row is the instruction or block you intended to recover.

  2. Click 'Restore'.

    Sequencer Item Recovery recreates the item from the complete sequence that was loaded and inserts a new copy at its original position in the current Sequencer tree.

  3. Inspect the Sequencer.

    Look at the restored item in the Advanced Sequencer. For a block, expand it and inspect its contained instructions as well.

  4. Save intentionally.

    Sequencer Item Recovery works in memory. Use N.I.N.A.'s normal save command when the restored state should be written to the sequence JSON file.

5. Restore an item while the sequence is running

This workflow is for a deletion noticed during an active run. It preserves the sequence position by pausing rather than cancelling.

  1. Pause N.I.N.A.

    Use N.I.N.A.'s 'Pause' control at the lower-right. Do not use a cancel or abort control. Wait until you can see that N.I.N.A. is paused.

  2. Open Sequencer Item Recovery.

    If necessary, go to Imaging and use the four-square Sequencer Item Recovery icon in the Tools group.

  3. Click 'Restore'.

    Select the row for the deleted item and click 'Restore'. Because N.I.N.A. does not expose its pause state to Sequencer Item Recovery, Sequencer Item Recovery asks you to confirm that the lower-right 'Pause' control has already paused the sequence.

  4. Confirm only when paused.

    Choose Yes only after confirming the pause in N.I.N.A. Choosing No leaves the sequence unchanged.

  5. Review, then continue.

    Check the restored item in the Sequencer. Use N.I.N.A.'s resume control to continue from the pause. Save normally after the sequence if the repaired sequence should be retained on disk.

The confirmation is deliberately explicit. Sequencer Item Recovery never tries to guess whether a physical imaging operation has stopped safely.

6. Buttons and status messages

'Compare now' refreshes the comparison immediately. Sequencer Item Recovery normally refreshes automatically about once per second, so this is useful when you have just changed the Sequencer and want an instant check. It never changes the baseline and never clears a visible 'Restore' row. A row remains available while its item is still missing. If no rows are shown, the button only performs that same automatic check immediately.

'Use current sequence as baseline' accepts the sequence currently on screen as the new fixed reference. It clears every visible 'Restore' row, including rows you may otherwise still have restored later. Therefore use it only after intentional edits and only when no recovery is still wanted. If no rows are shown, it starts the reference for later comparisons; it does not preserve a separate history or create a backup.

Restoring one row does not discard other still-visible 'Restore' rows. Each remaining row can be restored separately.

If the status says that Sequencer Item Recovery is inactive, open an Advanced Sequencer sequence. No camera connection and no running sequence are required for Sequencer Item Recovery to become active.

7. Limits and good habits

Sequencer Item Recovery is deliberately narrow: it restores recently deleted instructions and blocks from the sequence that is still open. It does not provide unlimited undo, restore an already saved deletion after the sequence has been closed, or replace backups.

For important imaging plans, save a named copy before broad edits. If a deletion happened earlier, use an earlier JSON sequence file or Windows File History. Sequencer Item Recovery is best for the moment when you notice the mistake and want to keep the rest of the current work.
