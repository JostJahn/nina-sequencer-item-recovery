Quick help

Notice. Restore. Continue.

The normal workflow takes only a few seconds when a Sequencer instruction or block was deleted by mistake.

Where Sequencer Item Recovery is

Load or create a sequence in N.I.N.A.'s Advanced Sequencer. Open Imaging, then click Sequencer Item Recovery's four-square icon in the upper-right Tools group. Closing the panel does not remove the icon; click the same icon to show Sequencer Item Recovery again.

Normal recovery

  1. Find the deleted item.

    Sequencer Item Recovery lists recently removed instructions and blocks. The newest deletion is at the top. The Instruction column uses the same name and useful settings shown in the Sequencer.

  2. Restore it.

    Click 'Restore' in that row. The item is inserted back at its original position in the in-memory Advanced Sequencer.

  3. Check and save.

    Review the restored item in N.I.N.A.'s Sequencer. Save the sequence normally if the repair should also be kept in its JSON file.

New unsaved sequences

Sequencer Item Recovery watches additions and deletions immediately; you do not need to click 'Compare now' or wait two seconds before deleting a newly added instruction. A background check also follows changes to item settings about once per second.

What the two panel buttons do

'Compare now' performs the automatic check immediately. It does not change the baseline and does not discard an existing 'Restore' row. With no rows, it is simply an immediate check.

'Use current sequence as baseline' accepts what is currently on screen as the new reference and clears every visible 'Restore' row. Use it only after intentional edits and only when nothing still needs restoring. With no rows, it starts a new reference for future comparisons; it is not a backup or undo history.

Recovery while a sequence is paused

Use N.I.N.A.'s lower-right 'Pause' control first. Do not cancel the sequence. Then click 'Restore' in Sequencer Item Recovery and confirm the safety message. Sequencer Item Recovery cannot inspect N.I.N.A.'s pause state, so it asks for your explicit confirmation. Check the result and use N.I.N.A.'s resume control to continue from the pause.

Important limit

Sequencer Item Recovery compares the open sequence with the last loaded sequence. It can help only while that sequence is still open and the deletion has been detected. It is not a replacement for saving versions or keeping backups. For a saved or closed sequence, use an earlier JSON file or Windows File History.
