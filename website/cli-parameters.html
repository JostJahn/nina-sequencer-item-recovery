CLI parameters

No command-line interface

Sequencer Item Recovery is loaded by N.I.N.A. as a plugin. It is not a standalone program and must not be started by double-clicking or from a terminal.

Available parameters

Sequencer Item Recovery has no command-line parameters, including no --help or -h option. Install the DLL in N.I.N.A.'s plugin folder and use it from the Imaging workspace.

Safety

Starting a plugin DLL directly is unsupported. Use N.I.N.A. to load Sequencer Item Recovery, open an Advanced Sequencer sequence, then show the tool from Imaging.
