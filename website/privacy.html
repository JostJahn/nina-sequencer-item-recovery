The Sequencer Item Recovery plugin

Sequencer Item Recovery runs locally in N.I.N.A. It uses the current Advanced Sequencer and the last loaded sequence only to find and restore deleted instructions or blocks. It has no telemetry, cloud synchronisation, account feature or network request. Sequence contents are not uploaded by Sequencer Item Recovery.
