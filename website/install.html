Manual installation

Install the ZIP package in N.I.N.A.

The package contains one plugin DLL. It is not a standalone application and does not have its own installer.

Before you start

Use N.I.N.A. 3.2.0.9001 or newer on Windows. Fully close N.I.N.A. before replacing a plugin DLL. Do not extract the file while N.I.N.A. is running.

Installation steps

  1. Download the package.

    Download SequencerItemRecovery-0.1.12.0.zip from this page.

  2. Verify the download.

    Compare the ZIP file's SHA-256 with the value on the Versions page. This confirms that the file was not changed in transit.

  3. Create or open the plugin folder.

    In Windows File Explorer, enter this path in the address bar:

    %LOCALAPPDATA%\NINA\Plugins\3.0.0\SequencerItemRecovery\

  4. Extract the ZIP there.

    The result must be SequencerItemRecovery.dll directly inside that folder, not inside an extra nested folder.

  5. Start N.I.N.A. again.

    Open Options → Plugins → Installed and check that Sequencer Item Recovery displays version 0.1.12.0.

Open the tool

Open or create an Advanced Sequencer sequence, switch to Imaging, then select the four-square Sequencer Item Recovery icon in the upper-right Tools group.

Earlier preview installation

If you installed the older preview named Recycle, close N.I.N.A. and remove its old NinaSequenceDiff plugin folder before starting N.I.N.A. again. Keep only the current SequencerItemRecovery folder so N.I.N.A. does not load two versions of the same plugin.
