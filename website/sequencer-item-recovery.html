What it does

When an instruction or complete block disappears from the sequence currently being edited, the plugin records a readable recovery row. It shows the time of detection and an instruction description using the same kind of wording and settings seen in the Sequencer, rather than internal JSON names. Select 'Restore' to insert the complete missing item at its original position.

The normal workflow is deliberately narrow: notice a deletion, check the row, restore the intended item, inspect it in the Sequencer, then save the sequence normally if the repair must be kept on disk.

What it does not do

This is not a full undo history, a general JSON editor, an automatic backup system or a replacement for saving sequence versions. It lists removed instructions and blocks only. It does not silently reverse additions, property changes, conditions or triggers.

Safe use during an imaging run

Use N.I.N.A.'s lower-right 'Pause' control first; do not cancel or abort the sequence. Once N.I.N.A. is visibly paused, use 'Restore', confirm the safety message, inspect the restored item, then resume N.I.N.A. The plugin never guesses the physical state of an imaging run.

Where to find it in N.I.N.A.

After installation, confirm the entry under Options → Plugins → Installed. The tool itself is opened from the Imaging workspace using its four-square icon in the Tools group. Closing the panel does not remove that icon.
