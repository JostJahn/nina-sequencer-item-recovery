Candidate verification

The candidate ZIP contains only the plugin DLL. Automated tests passed 22 of 22 cases. The exact DLL was installed and visibly loaded by N.I.N.A. 3.2.0.9001; moved duplicate blocks produced no false deletion, and a distinct three-item block was restored completely.

The package is a DLL archive, not a standalone EXE and not an installer. It is not Authenticode-signed. New or little-used downloads can therefore receive additional Windows security checks; compare the SHA-256 value before installation.

This candidate has not been published to GitHub or submitted as an update to the N.I.N.A. community plugin catalog.
