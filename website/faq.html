FAQ

Common questions

Short answers about installation, recovery and safe use.

Do I need N.I.N.A.'s plugin search?

No. Close N.I.N.A., download SequencerItemRecovery.zip, extract it to %LOCALAPPDATA%\NINA\Plugins\3.0.0\SequencerItemRecovery\, then start N.I.N.A. again. If an earlier Recycle preview is installed, remove its NinaSequenceDiff plugin folder first; do not keep both versions. See the download page.

What N.I.N.A. version is required?

Sequencer Item Recovery 0.1.3.0 targets N.I.N.A. 3.2.0.9001 or newer. It is a Windows plugin for the Advanced Sequencer.

Can Sequencer Item Recovery restore changed settings?

No. It intentionally lists only complete deleted instructions and blocks. It does not list additions, setting changes, conditions or triggers.

What if the sequence is running?

Use the lower-right N.I.N.A. 'Pause' control. Do not cancel. Use Sequencer Item Recovery's 'Restore', confirm the safety message only when N.I.N.A. is paused, review the item, then resume N.I.N.A. The detailed guide explains why the confirmation is required.

Why does Sequencer Item Recovery say inactive?

Sequencer Item Recovery becomes active after N.I.N.A. exposes an open Advanced Sequencer tree. Open Sequencer, choose Advanced, then load or create a sequence.

Do I need to click 'Compare now'?

No. Sequencer Item Recovery watches additions and deletions immediately, even when the Imaging panel is closed. You do not need to wait two seconds before deleting a newly added item. A background check also follows changes to item settings about once per second.

Will 'Compare now' remove a Restore row?

No. It only performs the automatic comparison immediately. It leaves the baseline and every row for an item that is still missing unchanged. With no rows present, it is simply an immediate check.

What does 'Use current sequence as baseline' discard?

It accepts the current state as the new reference and clears every visible 'Restore' row. Use it only after intentional edits and only after restoring every item you may still want. With no rows, it starts a new reference for later comparisons; it is not a backup or undo history.

Why did the recovered row disappear?

That is expected. Once the item is back in the current tree, it is no longer a deletion compared with the baseline.

Can I use it as a backup system?

No. It is a short-term recovery tool for an open sequence. Save named copies of important sequences and use Windows File History or another backup for longer-term recovery.

Does Sequencer Item Recovery send my sequence to a website?

No. Sequencer Item Recovery compares and restores the open sequence locally inside N.I.N.A. The download website is static and does not receive your sequence.

Why might Windows show a warning for a download?

Windows and security products can inspect new or little-used downloads more closely. Verify the SHA-256 value on the Versions page and download only from the publisher's official location.
